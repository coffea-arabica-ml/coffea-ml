# Dataset BRACOL

Este projeto usa o dataset BRACOL (Krohling, Esgario & Ventura, 2019).

1. Baixe manualmente em: https://data.mendeley.com/datasets/yy2k5y8mxg/1
2. Extraia o conteúdo dentro de `data/raw/`
3. Rode `python organize_dataset.py` para dividir em treino/validação/teste

O download automático via script não é confiável para o Mendeley Data
(a página usa links assinados por sessão), por isso esse passo é manual.
